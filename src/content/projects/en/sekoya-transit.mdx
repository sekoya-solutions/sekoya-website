- **A deterministic simulation.** The game rules are plain C# with no Unity types, and change only through the player's commands: the same seed and the same commands always give the same world. A seeded random generator, fixed-point numbers and a hash of the full state make that testable.
- **Procedural maps up to 512 × 512 tiles.** Terrain, towns and industries come from deterministic noise and placement. The map is drawn as custom mesh chunks, chosen after both approaches were measured in WebGL.
- **Balance as data, checked by simulation.** Vehicles, industries, cargo and contracts are described in validated JSON. A headless tool plays whole games on the real engine, with a scripted player, to check the pace of progression.
- **Saves that keep working.** The format is versioned, and saves from recent earlier versions are migrated on load.
- **Every change checked.** Each pull request builds and tests the engine in .NET and checks formatting and documentation. Unity tests run on the main branch, and the demo is published again after each merge that changes the game.
- **Two languages**, English and French, and original art.
