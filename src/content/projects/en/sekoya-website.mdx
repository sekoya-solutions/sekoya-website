- **Decisions written before the code.** Each technical choice is an Architecture Decision Record (ADR), with the options considered.
- **Measured figures, never typed by hand.** Every figure shown comes from a dated measurement. A fact not yet provided stays a visible marker, which a check lists before going live.
- **Almost no JavaScript.** CSS filters, pure CSS animations that stop when the system asks for less motion, and every page complete without JavaScript.
- **Two languages:** French at the root, English under /en/, each page linked to its translation.
- **Tested on every change:** unit tests, end-to-end and accessibility tests on the built site.
